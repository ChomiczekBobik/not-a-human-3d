# НЕТ, Я НЕ ВЕЛИЧАНИН (3D) — пародия на «No, I'm not a Human»

Статическая браузерная игра без сборки и без npm: Three.js идёт по CDN, а сцены,
риги, текстуры, GLB-модели и локальные OGG-эффекты подключаются как обычные файлы.
Заливается на GitHub Pages как есть.

## Запуск локально

Двойной клик по `serve.bat` (нужен Python) → открой **http://localhost:8080**.

Или вручную:
```
cd not-a-human-3d
py -m http.server 8080
```

Открывать `index.html` через `file://` нельзя — ES-модули по CORS не загрузятся.

## Публикация на GitHub Pages

### Через GitHub API (без git и CLI)

Скрипт использует только Python из установленной системы и REST API GitHub.
Для матрицы файлов подходит Contents API: в beta-релизе 131 файл / ~2.1 MiB,
тяжёлые dev-артефакты исключены через `.gitignore` и один общий список исключений.

1. Создай **personal access token (classic)** на `github.com/settings/tokens` со scope `repo`.
2. Не вставляй токен в чат или файлы. Установи его только в текущий PowerShell:
   ```powershell
   cd C:\Users\user\not-a-human-3d
   $s = Read-Host -AsSecureString 'GitHub PAT'
   $env:GITHUB_TOKEN = [System.Net.NetworkCredential]::new('', $s).Password
   Remove-Variable s
   ```
   После публикации: `Remove-Item Env:GITHUB_TOKEN`.
3. Проверь состав, сборку и опубликуй:
   ```powershell
   python tools\github_publish.py --dry-run
   python tools\build_release_zip.py
   python tools\github_publish.py --owner <твой_ник> --repo not-a-human-3d --enable-pages --release --asset dist\not-a-human-3d-0.1.0-beta.1.zip
   ```
4. Открой `https://<твой_ник>.github.io/not-a-human-3d/`. Первая сборка Pages занимает 1–3 минуты.

Скрипт создаёт репозиторий, если его нет, загружает файлы через Contents API,
включает Pages с ветки по умолчанию и создаёт prerelease `v0.1.0-beta.1`.
Если репозиторий уже существует — запроси токен, в котором есть Contents/Pages permissions,
и скрипт обновит файлы по SHA и прикрепит asset к релизу.

### Через сайт GitHub

1. Создай репозиторий `not-a-human-3d` → **Add file → Upload files**, загрузи распакованный
   `dist\not-a-human-3d-0.1.0-beta.1.zip`.
2. **Settings → Pages → Deploy from a branch → Branch: main → /(root) → Save.**
3. Через 1–3 минуты игра будет на `https://<твой_ник>.github.io/not-a-human-3d/`.

### Через обычный git будет проще, если установить Git

```
git init
git add .
git commit -m "beta 0.1.0-beta.1"
git branch -M main
git remote add origin https://github.com/<твой_ник>/not-a-human-3d.git
git push -u origin main
```

`.nojekyll` уже в проекте — Jekyll не будет трогать служебные файлы.
`assets/models/tripo_heavy.glb`, `shots/`, `dist/`, `*.log` и кэши Python не публикуются.

## Управление

| Действие | Клавиша |
|---|---|
| Ходить | W A S D (Shift — быстрее) |
| Присесть / встать | C. В приседе — ниже камера, медленнее шаг и тише шаги |
| Действие | E. Когда предмет доступен, вокруг него появляется тёплый жёлтый контур |
| Список дел | TAB или кнопка «дела» слева |
| Смотреть | мышь (указатель захватывается кликом) |
| Вопросы, осмотр, решения | кнопки мышью в диалоге |
| Выход из захвата мыши | ESC (клик — вернуться) |
| Чит: пропустить ночь | набрать `homka` (или `рщьлф` — раскладка любая). Ночью — мгновенный скип. Днём/на титуле — армирование: в HUD появится `zzz`, ночь пролетит сама, когда ляжешь спать **[E] у кровати в спальне** |

## Звуки

Эффекты лежат в `assets/sfx/` и грузятся локально: во время игры внешний хостинг
звука не используется. Источники, исходные имена файлов и лицензии собраны в
[`assets/sfx/SOURCES.md`](assets/sfx/SOURCES.md). Лицензия использованных записей — CC0-1.0.

## Что уже есть

- 3D-квартира, коридор, улица, «Бедронка», подвал и лицей второго дня.
- Просторная квартира: центральный проход свободен, кофейный столик не блокирует шаг.
- Перестроенная «Бедронка»: короткие островные ряды, свободный кассовый холл, витрины у правой стены
  и прямой маршрут от входа до Людмилы.
- Процедурный риг персонажа (`src/rig.js`): суставы hips/spine/chest/neck/head, руки, ноги,
  параметры `height, girth, headScale, eyeCount, eyeGlow, extraArms, fingers, coat, hat, mouth, shadow`.
- Процедурные позы (`src/anim.js`): idle, walk, knock, lean, creepy, talk, freeze.
- 7 дней, ночные посетители, вопросы через дверь, осмотр в глазок, дневной суд и выбор судьбы.
- Счётчик человечности (3 сердца), скример, 3 концовки.
- Гибридный звук (`src/audio.js`): 22 локальных CC0 OGG — шаги по дереву/снегу, стук,
  двери, скрип, ткань приседания, монеты, звонок магазина, клик интерфейса, ветер и комнатный тон.
  Если OGG недоступен, автоматически остаётся синтезированный WebAudio-фолбэк.
- Редкая криповая отдышка во время бега, синтезированная поверх реальных шагов.

## Как править сюжет и персонажей

Все ночи лежат в `src/game.js` в массиве `NIGHTS`. У каждой ночи:
- `visitor` — параметры модели (передаются в `createHumanoid`);
- `lines` — две реплики перед диалогом;
- `questions` — вопросы игрока и ответы;
- `look` — то, что видно при осмотре в глазок;
- `goodOpen / goodClose / badClose` — тексты последствий;
- `human: true/false` — определяет правильное решение (нелюдь + «открыть» = смерть).

Добавить персонажа = добавить объект в `NIGHTS`. Добавить новую позу = функция в `pose` (`src/anim.js`)
+ `case` в `Game.updateVisitor`.

## Собственные модели (GLB)

1. Кидай исходники в `assets/models/src/` (GLB, текстуры внутри, любой разрешение).
2. Оптимизируй (Pillow уже ставится):
   ```
   py tools/optimize_glb.py assets/models/src/gena.glb -o assets/models/gena.glb
   py tools/optimize_glb.py assets/models/src/hero.glb -o assets/models/hero.glb --size 2048
   ```
   Выход: все текстуры <= 1024 px (или 2048 для героя), baseColor без альфы -> JPEG q90,
   normal/roughness/occlusion -> PNG. Оригинал не меняется.
3. Веб-файлы в `assets/models/*.glb` попадут в игру загрузчиком `GLTFLoader`.

Рекомендуемые размеры: гости квартиры 1024 px, герой крупного плана 2048 px.
Оригиналы из `assets/models/src/` на GitHub Pages не нужны — достаточно оптимизированных.

## Технически

- Three.js **0.169.0** по CDN (`unpkg`, `three/addons/` для PointerLockControls/OrbitControls).
- Риг не скиннинговый: сегменты-меши на суставах, ноль ассетов и нулевая загрузка.
- Требуется WebGL2 и свежий Chrome/Edge/Firefox. Мобильного управления пока нет.

## Производительность

Игра рассчитана на слабые ноутбуки (проверено на Intel UHD Graphics 620).

- **Full HD-профиль**: бэкбуфер не бывает больше 1920×1080 — даже на 4K-экране или при
  `devicePixelRatio` 2+ игра рендерит 1:1 к Full HD. Множитель пересчитывается на resize.
- **Адаптивное качество** — мелкая лестница 100 → 90 → 82 → 74 → 66 → 58 % (от Full HD),
  шаг ~8–10%: на Full HD это ~150–300 тыс. пикселей, поэтому ступени не видны как «прыжок».
  Блум уходит только на q4+, тени — на самом дне (q5). Уровень меняется по фактическому FPS,
  композер получает новый pixel ratio.
- **Кадровый лимит** 60 fps (30 в меню), чтобы не греть GPU на 120/144-Гц экранах.
- **Блум на четверти разрешения**: цепь UnrealBloomPass — около 10 размытий, на полном
  Full HD это была самая дорогая часть кадра (7–9 мс). Четверть бэкбуфера + компенсация
  радиуса/силы — вчетверо дешевле при том же читаемом гало ламп.
- **Тени 10 Гц**: кубическая карта point-света — 6 граней 512²; статичной квартире чаще не нужно.
- **Статик-батчинг**: инстансы по параметрам геометрии и материала, корзины 4 м по XZ —
  фрустум отсекает целые инстанс-проходы («не рисуем то, куда не смотрим»).
- **Коридор за входной дверью гаснет**: дверь в игре не открывается, подъезд виден только
  через глазок — группа включается на время глазка (−13 вызовов в самом частом кадре).
- **Плоские недосягаемые поверхности**: потолки, пол и стены подъезда, задние двери соседей —
  односторонние плоскости вместо боксов; у невидимых потолков сняты текстуры и bumpMap.
- **Снег на улице** анимируется в вершинном шейдере, без пересчёта 1200 частиц на CPU.
- Пул из двух PointLight на три уличных фонаря; вывеска и дверь «Бедронки» делят один источник.

Ручные настройки через URL:

| Параметр | Действие |
|---|---|
| `?q=0` … `?q=5` | фиксировать качество (0 — Full HD 100%, 5 — 58% без блума и теней) |
| `?fps=30` | ограничить кадры (по умолчанию 60) |
| `?fps=0` | без ограничения кадров |
| `?bin=3` | размер корзины батчинга, м (по умолчанию 4) |

Быстрый запуск на слабом ноуте: `http://localhost:8080/?q=4`.

Проверка активного режима в консоли браузера: `__perf()`; принудительно переключить: `__setQuality(4)`.

Замеры (headless Chrome, Intel UHD Graphics 620, окно 1258×622, `?q=0` — 100%, блум и тени вкл.):

| Сцена | Вызовов/кадр | Треугольников | FPS |
|---|---|---|---|
| Квартира | 75 | 2697 | 60.1 |
| Улица | 96 | 2589 | 60.1 |
| Магазин | 129 | 8147 | 59.9 |
| Подвал | 44 | 931 | 60.0 |

Инструменты замеров: `tools/measure.py` (адаптивный прогон по 4 сценам), `tools/measure2.py`
(фиксированный q=0, блум вкл/выкл), `tools/measure3.py` (главный проход / тени / блум по отдельности).
